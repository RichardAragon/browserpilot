Sales Orders can be created
through the browser.

Verified in local Dolibarr

The assistant no longer rejects a CRM record simply because it is commercial or financial. It preserves the requested record type, honors delegated customer selection, and proposes the available browser workflow.

The live result

A real LLM discovered the Sales Orders list and customer form. Dolibarr did not expose the customer reference until after draft creation, so the controller used two reviews: one to create the draft, then one to complete its reference. It created one draft and saved its reference once. Fresh browser readback verified the original generated document identity and the following values.

Changes driven by testing

  • Object type is independent of the record name. Names containing “Opportunity” do not change a Sales Order request.
  • Existing related records can be selected during setup when the user delegates that choice.
  • Draft-first creation tracks the generated document identity and retains the original operation through retries.
  • Search retains previously observed list evidence and handles navigation delays.
  • Verification uses the original document, distinguishes customer and external references, and requires literal visible evidence.
  • The dashboard labels both review stages and orders screenshots by capture time.

Validation

133 automated tests, plus real-browser dropdown and saved-text checks. The live model was gpt-6.1-sol. All platform changes used browser controls with platform-specific adapters disabled. The final readback took 12.641 seconds; this recovery timing is not end-to-end creation speed.

Practical limits

  • This is an iterative development test, not an API-speed or universal-compatibility benchmark.
  • The draft-first path currently covers a name/reference and delegated existing relationships. It does not add line items, validate, issue, send or pay.
  • Customer reference and External ref can be separate fields. Generated documents are tracked by their observed document identity; references are not assumed unique.
  • A process restart before reference review can leave a known draft needing manual completion; the controller does not create it again.
  • The earlier isolated YouTube test form was not submitted. Its original intent fence remains in the isolated development workspace.

Raw browser evidence and operation history stay in the local app workspace. See structured results and the user guide.
