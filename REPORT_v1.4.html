What changed

  • Assistant receives verified task history and the explicit latest request
  • Platform-neutral source-record field references in task contracts
  • Scoped visible-record evidence rather than an unlabeled card or search chip
  • Support for detail views without standard form/main landmarks
  • Reuse observed detail URLs with exact visible identity checks for source rechecks
  • Read source again before input; changed sources rebuild the review on the same blank form without inheriting approval
  • Select explicit input-combobox relationships as existing options instead of typing plain text
  • Approval covers source identity, field and resolved value
  • Interrupted final submissions verify the approved snapshot without re-resolving or replaying creation

Validation

175 tests passed, including rendered browser fixtures, source-value drift before approval, and lost-session recovery against the approved snapshot. The real Odoo task used one form opening and one final submission. Two read-only lookup failures during development exposed missing detail landmarks and duplicate search-chip text; both were fixed before submission.

The final creation attempt took 96.234 seconds. This excludes earlier development attempts and approval time; API-level speed has not been established.

A second proposal-only test asked for the same Account as “the last Opportunity you successfully created.” The assistant correctly identified Richard Test from verified task history; no extra CRM record was created.

The installed Windows 1.4 build was restarted and rechecked the original operation successfully. The journal still showed exactly one final creation; recovery submitted no duplicate.

Scope

  • The new reference workflow was live-tested on Odoo; it has not yet been live-tested on Salesforce, HubSpot or Dolibarr.
  • Uses visible English UI and accessible controls; some search-and-select pickers or unusual detail layouts can still require refinement.
  • The source and target cannot be locked atomically through browser checks; external changes during Save remain possible.
  • Record dependencies currently support general record creation in the same connection, not cross-platform joins or dependency chains.
